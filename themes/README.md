# الثيمات

كل مجلد هنا ثيم بصيغة **Omarchy** نفسها: `colors.toml` + `backgrounds/` (واختيارياً ملف `name` باسم عربي).
أول ملف في `backgrounds/` (بالترتيب الأبجدي) هو الخلفية الافتراضية للثيم.

- تبديل الثيم: `SUPER + T` أو `zool-theme set <اسم>`
- تثبيت ثيم من الإنترنت (أي ثيم Omarchy فيه `colors.toml`): `zool-theme-install <رابط git>` — قائمة: <https://omarchy.org/themes/>
- ثيمك الخاص: ضعه في `~/.config/zool/themes/<اسم>/`

## الخلفيات

- `1-meroe-dunes.jpg`: لوحة مرسومة بألوان الثيم — يولّدها `branding/make_theme_backgrounds.py`
- `photo-*.jpg`: صور من السودان (المصدر في `branding/photos/`) مركّبة على لوحة 16:9 لتظهر كاملة بلا قص
