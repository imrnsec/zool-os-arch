# migrations — ترحيلات التحديث

كل ملف `*.sh` هنا يُنفَّذ **مرة واحدة** (بصلاحيات root) على الأنظمة المثبّتة عند تشغيل `zool-update`،
بترتيب الاسم. استعمله لما لا يكفي فيه نسخ الملفات: تثبيت حزمة جديدة، تفعيل خدمة، حذف ملف قديم…

- سمِّ الملف بالتاريخ: `20261112-add-foo.sh`
- اجعله آمناً عند إعادة التشغيل (`pacman -S --needed`، `systemctl enable` …)
- الأنظمة المثبّتة من ISO جديد تُعدّ منفِّذة لكل الترحيلات الموجودة وقت بناء ذلك الـ ISO.

مثال:

```bash
#!/bin/bash
pacman -S --needed --noconfirm some-package
```
